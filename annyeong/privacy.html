🔒 광고도, 광고 식별자 추적도 없는 작은 날씨 앱이에요. 닉네임·장소 등 사용자 입력 정보는 이 기기에만 저장돼요. 오류가 나면 익명 진단만 보낼 수 있어요.

1. 개요

"안녕, 오늘"은 매일 아침 현재 위치의 날씨를 귀여운 캐릭터 일러스트와 함께 한 화면에 보여드리는 작은 앱입니다. 닉네임, 저장한 장소, 캐릭터·배경 설정 같은 사용자 입력 정보는 이 기기에만 저장되며 어떤 외부 서버로도 전송되지 않습니다.

2-2. 위치 정보 (앱 사용 중에만)

  • 현재 위치의 날씨를 보여주기 위해 앱 사용 중에만 위치 정보를 요청합니다.
  • 위치 좌표는 장기 저장하지 않으며, 매번 사용 시 새로 조회합니다. (마지막 조회 위치는 최대 15분간 메모리에만 캐시하여 화면 전환 시 네트워크 부하를 줄입니다.)
  • 위치 좌표는 Open-Meteo 날씨·대기질 API에 전송되어 날씨를 받아오는 데만 사용됩니다. 한국이고 기상청 키가 있는 빌드에서는 공공데이터포털(기상청)에도 격자 좌표를 보냅니다.
  • 장소 이름으로 찾을 때는 Open-Meteo 지오코딩에 입력한 지명이 전송됩니다. 좌표→지역명 변환은 기기 지오코더(Google/Apple)를 씁니다.

2-3. 자동으로 수집되는 익명 오류 정보

앱이 예기치 않게 종료되거나 오류가 발생할 경우, 문제 해결을 위해 아래 익명 오류 정보가 Firebase Crashlytics (Google LLC)로 전송됩니다.

  • 기기 모델명 및 OS 버전
  • 오류가 발생한 코드 위치 (스택 트레이스)
  • 앱 버전
  • 익명의 설치 식별자 (Firebase Installation ID) — 광고 식별자가 아닙니다

이 정보는 특정 개인을 식별하는 데 사용될 수 없으며, 닉네임·생년월일·위치 좌표·저장한 장소 이름·여행 일정·사용자 추가 명언은 포함되지 않습니다.

3. 정보 처리 방식

  • 닉네임·저장한 장소·캐릭터 설정 등 모든 사용자 입력 정보는 이 기기 안에서만 처리됩니다.
  • 위치 좌표는 Open-Meteo 날씨 API 호출에만 사용되며, 자체 서버에 저장되지 않습니다.
  • 광고 식별자, 행동 추적 데이터는 수집하지 않습니다.

5. 데이터 보관, 삭제 및 자동 백업

보관 및 삭제

  • 앱을 삭제하면 기기 내 모든 데이터가 영구 삭제됩니다.
  • 저장한 장소, 사용자 추가 명언 등은 설정에서 개별 삭제할 수 있습니다.

Android 자동 백업

앱은 Android의 자동 백업 기능(Android Auto Backup)을 사용합니다. Wi-Fi 연결 및 충전 중일 때, 사용자 본인의 Google 계정 드라이브에 설정 데이터가 자동으로 백업됩니다.

  • 이 백업은 개발자가 아닌 사용자 본인의 Google 계정에 저장되며, 개발자는 이 데이터에 접근할 수 없습니다.
  • Google 백업 정책: https://policies.google.com/privacy

7. 아동 개인정보

본 앱은 모든 연령 사용자를 대상으로 한 일반 날씨 앱이며, 어린이로부터 의도적으로 개인정보를 수집하지 않습니다.

8. 사용자의 권리 · 옵트아웃

  • 데이터 삭제: 앱을 기기에서 삭제하면 모든 로컬 데이터가 함께 삭제됩니다.
  • 진단 데이터: 광고 ID를 쓰지 않습니다. 오류 보고를 멈추려면 앱을 삭제하면 됩니다.
  • 위치 권한 철회: 기기 설정 → 앱 → 안녕, 오늘 → 권한에서 위치를 끄면 됩니다. 끄면 현재 위치 날씨를 보여드리지 못해요.

9. 개인정보처리방침 변경

이 방침이 변경되는 경우, 본 페이지 상단의 "시행일"을 갱신하고 앱 업데이트 내역에 공지합니다.
중요한 변경(새로운 데이터 수집 등)이 있을 경우 앱 내에서도 별도 안내합니다.
