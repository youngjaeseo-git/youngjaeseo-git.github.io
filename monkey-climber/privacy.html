🐵 Monkey Climber 개인정보 처리방침

최종 수정: 2026년 10월 5일

1. 수집하는 개인정보

Monkey Climber(이하 "앱")는 게임 기능, 이용 분석, 오류 진단 및 보상형 광고를 위해 다음 정보를 처리합니다:

  • 플레이어 닉네임 — 앱이 자동 생성하거나 사용자가 변경한 이름과 식별번호로, 공개 리더보드와 원격 기록 저장에 사용
  • 사용 분석 및 진단 — 플레이 시작·종료, 사망·부활, 광고 결과, 성장 구매, 앱 버전과 오류·크래시 정보. Firebase SDK는 앱 인스턴스·설치·세션 식별자, IP에서 파생된 대략적 위치, 기기·운영체제 및 진단 정보를 처리할 수 있습니다. 원시 오류와 스택 정보도 오류 진단 서비스로 전송될 수 있습니다.
  • 게임 기록 — 최고 점수, 최고 높이, 누적 코인, 플레이어 이름, 레벨과 기록 시각
  • 계정 식별자 — 익명 로그인 시 Firebase에서 자동 생성하는 고유 ID
  • 친구·선물 기록 — 친구 요청 시 발신 익명 ID, 입력한 수신 친구 코드, 요청 시각과 상태; 친구 목록의 이름과 ID; 에너지 선물 시 발신·수신 익명 ID, 종류, 수량, 생성 시각 및 수령 여부

앱은 실명, 이메일, 전화번호 입력을 요구하지 않습니다. 닉네임에는 개인정보를 입력하지 않도록 주의해 주세요. 앱은 별도 회원가입 화면 없이 Firebase 익명 인증으로 원격 기록을 식별합니다. 기울기 조작에 사용하는 원시 가속도 값은 해당 조작을 위해 메모리에서 처리하며 앱이 직접 저장하거나 전송하지 않습니다.

2. 정보의 이용 목적

  • 리더보드 순위 표시
  • Firebase Firestore에 최고 점수, 최고 높이, 누적 코인, 플레이어 이름 저장
  • Firebase 연결 시 원격 최고 점수가 기기의 최고 점수보다 높을 때 그 최고 점수 복원
  • 친구 시스템 (친구 코드 기반)
  • 게임 이용 흐름 분석, 난이도 개선 및 오류 진단
  • 보상형 광고 제공, 광고 성과 측정·부정 사용 방지 및 광고 동의 선택 처리

3. 정보의 보관 및 파기

  • Firebase Firestore에는 최고 점수, 최고 높이, 누적 코인, 플레이어 이름을 저장합니다. 현재 앱 시작 시 원격 저장본에서 복원하는 항목은 최고 점수입니다.
  • 성장, 업적, 일일 미션, 설정 등 진행 정보는 기기에 로컬로 저장됩니다. 레벨은 리더보드에 포함되며, 선택 캐릭터·일부 업그레이드와 게임 결과는 이용 분석에도 전송됩니다.
  • 앱 내 설정의 데이터 초기화는 기기에 저장된 로컬 데이터를 초기화합니다. 이 동작은 Firebase 서버 데이터나 익명 인증 사용자를 삭제하지 않습니다.
  • 앱 삭제나 로컬 초기화는 외부 서비스에 저장된 기록을 삭제하지 않습니다. 같은 익명 사용자로 연결되면 원격 최고 점수가 다시 반영될 수 있습니다. 기기 백업의 복원 여부는 기기와 운영체제 설정에 따라 달라질 수 있습니다.
  • 원격 게임 데이터의 삭제를 요청하려면 youngjae.seo@gmail.com으로 Monkey Climber 삭제 요청과 현재 닉네임·태그 등 게임 정보를 보내 주세요. 개발자는 필요한 경우 일회용 닉네임 변경 등을 요청해 해당 기록의 실제 소유자인지 확인합니다. 공개된 닉네임이나 친구 코드만으로 다른 사람의 기록을 삭제하지 않습니다. 확인 후 개발자가 관리하고 해당 Firebase UID에 직접 연결할 수 있는 프로필·닉네임·점수·높이·순위 기록, 친구 요청·관계, 선물 및 기타 Firestore 데이터를 삭제하며, 삭제 가능한 경우 Firebase 익명 인증 사용자도 삭제합니다. 관련 이용자의 다른 기록을 임의로 삭제하지 않습니다. 고정 처리 기간은 약속하지 않습니다.
  • 앱에는 서버 기록이나 익명 인증 사용자를 자동으로 삭제하는 기능이 없습니다. 보상형 광고 및 분석·진단 서비스의 정보는 각 서비스의 보관·삭제 정책과 실제 설정에 따라 처리되며, 게임 기록 삭제가 모든 외부 SDK 정보의 즉시 삭제를 뜻하지 않습니다.
  • Firebase 공식 안내에 따르면 인증 과정에서 기록된 IP 주소는 몇 주간, 그 밖의 인증 정보는 개발자가 해당 인증 사용자 삭제를 시작할 때까지 보관되며, Crashlytics 오류 정보와 관련 식별자는 90일 보관 후 삭제 절차가 시작됩니다. 서비스의 백업 삭제에는 추가 시간이 걸릴 수 있습니다. Firebase와 Google의 아래 개인정보 안내를 참고해 주세요.

문의·삭제 요청을 위해 보내신 이메일 주소와 메시지, 게임 식별 정보는 요청 확인·처리·답변에 사용합니다. 앱이 이메일을 자동으로 수집하는 것은 아닙니다.

4. 제3자 제공

앱은 아래 Google 서비스를 사용합니다. 닉네임과 순위 기록은 다른 이용자가 조회할 수 있으며, 친구·선물 기능에서는 관련 식별자와 관계 정보를 처리합니다. 서버 연결과 기록 저장은 별도 클라우드 활성화 스위치 없이 앱의 기능 경로에서 실행됩니다.

  • Firebase Anonymous Authentication (Google) — 익명 사용자 식별
  • Cloud Firestore (Google) — 원격 게임 기록, 리더보드, 친구·선물 기록 저장
  • Firebase Analytics (Google) — 게임 이용 분석
  • Firebase Crashlytics (Google) — 오류·크래시 진단
  • Google AdMob — 보상형 광고 제공, 광고 성과 및 부정 사용 방지
  • Google UMP — 광고 동의 정보와 광고 개인정보 선택 처리

Firebase의 개인정보 처리방침: firebase.google.com/support/privacy

Google의 개인정보 처리방침: policies.google.com/privacy

5. 아동 보호

Play Console에 선언한 대상은 13세 이상 청소년과 성인입니다. 이 연령 선언만으로 특정 연령의 데이터가 수집되지 않는다는 뜻은 아닙니다. 광고 개인정보 선택은 실제 지역과 서비스 설정, 사용자 선택에 따릅니다.

6. 광고

앱은 사용자가 선택하면 보상형 광고를 표시합니다. 광고 요청이 허용된 상태에서는 광고를 미리 로드할 수 있으므로 광고 보기 버튼을 누르기 전에도 광고 요청과 관련된 데이터 처리가 발생할 수 있습니다. Google AdMob은 광고 제공 과정에서 광고 식별자, 대략적인 위치, 앱 상호작용 정보, 진단 정보 등을 처리할 수 있습니다. 앱은 Google UMP를 통해 동의 정보를 갱신하고 필요한 동의 화면을 요청한 뒤 광고 요청 허용 상태를 확인합니다. UMP가 개인정보 선택 화면을 요구하는 경우 앱 설정에서 해당 화면을 열 수 있습니다. 개인화 여부와 동의 적용 범위는 실제 Google 설정·지역·사용자 선택에 따릅니다. Analytics 및 Crashlytics에는 별도의 앱 내 수집 중지 설정이 없습니다.
